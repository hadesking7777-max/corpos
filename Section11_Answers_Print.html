Answers to Section 11 — Questions for the Dev Team

Re: Dev Team Internal Review — Project A & Project B  |  20 November 2026

Q1Hardware for Recipe Validation (R05)

Our available hardware is still to be confirmed. Validating the recipe at the full 1.5B scale will most likely require short-term GPU rental, which should be budgeted from the start.

Q2Experience with Remote Cluster Scripts

We have experience with deployment automation, monitoring and recovery for distributed systems on Kubernetes and AWS: health checks, automatic restarts, failure detection, retries and centralized logging. GPU-training-specific failures are new to us: NCCL communication hangs, GPU errors, checkpoint resume and loss-spike rollback. Since we will not have access to the target cluster, we will validate the scripts on our own or rented infrastructure first, and ship pre-flight checks, a dry-run mode and automatic diagnostic bundles for remote troubleshooting.

Q3Training Feasibility and Performance

Achievable with Megatron-Core or torchtitan. A 1.5B model needs only data parallelism (FSDP/ZeRO), with FlashAttention and BF16. Realistic range: 30–40% MFU, ~33–44K tokens/s per H100, subject to benchmarking. I suggest planning at 35% MFU: ~4.5–5 weeks on 16 × H100.

Q4Use of Open-Source Frameworks

Use an established open-source framework for distributed training, implement the model definition in-house (code only, no external weights), and track lineage from day one (data versions, configs, checkpoints). This needs Blue Team agreement.

Q5Dataset Availability (1T Tokens)

Feasible in total: English web and permissively licensed code are plentiful. The bottlenecks are target-language and log/command/security data, which may need repeated epochs, synthetic data and extra quality filtering.

Q6Prompt Injection and Hallucination Testing

Injection: hide instructions in event fields (HTTP headers, filenames, commands). A test passes if the model treats them as data and the classification and JSON schema stay unchanged; canary strings detect instruction following.

Hallucination: every output entity must be traceable to the input, the model should abstain when information is missing, and answers should stay consistent across paraphrases. Constrained decoding enforces valid JSON.

Q7Web-Service Test Automation (P07, P09)

With 2.9 M/M plus 0.4 M/M per month of maintenance, full UI automation of frequently changing web services is not sustainable. I propose automating the core scenarios at API level and covering the rest with manual checklists.

Q8Messenger Notifications (P03)

Telegram Bot API over outbound HTTPS. This requires the delivery point in the Blue Team network to reach api.telegram.org; otherwise a relay or email fallback, with retries and failure logging.
